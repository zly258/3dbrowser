## 4. 已知取舍

1. **v9 需要转换**：`scripts/nbim-v8-to-v9.mjs <v8> <v9>`；运行时同时支持 v8/v9。
2. **粗 LOD 省略远景小构件**：概览时 5–20cm 的构件不参与点选/框选；放大到 ~220px 自动升级全量。
3. **法线 8bit**：约 1° 精度，工业钢构肉眼无明显差异（同机位截图约 7% 像素有量化级差异）。
4. **全量 1271 块需要约 2.6 GB 堆**：4 GB 浏览器可用；2 GB 机器走粗 LOD（约 1.65 GB）。

## 2.4 自适应分辨率 LOD（可选，2026-11-13）

按当前视口“1 像素对应多少世界单位”推导实例尺寸阈值（约 1.35px），远景只剔除投影小于该值的构件，保留真实几何，不做线框代理。

全模型 1,271 块：

| 指标 | 全量绘制 | 自适应分辨率 LOD |
|---|---:|---:|
| 充满视图绘制三角面 | 186,284,229 | **47,100,000** |
| draw call | 1,271 | 1,271 |
| 充满视图单帧（软件渲染） | ~500 ms | **117 ms** |
| 局部放大单帧 | ~145 ms | **62–67 ms** |
| 堆（GC 后） | 2,531 MB | **1,186 MB** |
| 常驻分块 | 1,271/1,271 | 1,271/1,271 |
| 远景显示 | 完整实体 | 真实几何（省略 <1.35px 小构件） |

- 默认关闭（全量几何）；仅显式加 `?coarseLod=1` 时启用，子集/LMB 不受影响。
- 放大后按“已应用阈值 vs 当前期望阈值”重载更细几何，带 1.5s 冷却，不会反复卸载。
- 点选/框选只覆盖当前 LOD 中保留的构件；放大细化后恢复。

### 2.4.1 可选：渲染预算 + 线框代理

`?renderBudget=auto` 时可在 7,000 万面 / 700 块预算外把远景分块压成合并线框代理（1 draw call），实测 70.0M 面 / ~490 call / 150–190ms，点选/框选与全量一致。默认 `full`（关闭），避免远景显示为空线框。
